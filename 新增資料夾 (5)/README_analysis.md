# Gemini 自殺危機對話混合分析

## 分析方法論

### 🔍 質性分析 (Qualitative)
1. **主題分析 (Thematic Analysis)**
   - 識別核心主題: 死亡、孤獨、創傷、自我照顧等
   - 提取關鍵敘事片段

2. **敘事分析 (Narrative Analysis)**
   - 追蹤情緒轉折點
   - 繪製心理狀態變化弧線

3. **話語分析 (Discourse Analysis)**
   - 分析 Gemini 的療癒策略
   - 識別有效的介入技巧

### 📊 量化分析 (Quantitative)
1. **情感分析 (Sentiment Analysis)**
   - 正負向情緒詞頻統計
   - 情緒強度量化評分

2. **風險評估 (Risk Assessment)**
   - 自殺風險指標追蹤
   - 保護因子識別

3. **時間序列分析**
   - 情緒變化趨勢
   - 危機緩解時間點

### 🔄 混合分析 (Mixed Methods)
- 質性主題的量化呈現
- 敘事弧線的數據視覺化
- 策略效能的統計驗證

## 使用方式

### 1. 安裝相依套件
```bash
pip install -r requirements.txt
```

### 2. 執行分析
```bash
python gemini_conversation_analysis.py
```

### 3. 查看結果
分析結果將儲存在 `analysis_results/` 資料夾:
- `emotion_analysis.csv` - 情緒量化數據
- `healing_strategies.csv` - 療癒策略時間軸
- `risk_assessment.csv` - 風險評估數據
- `thematic_analysis.json` - 主題分析結果
- `narrative_arc.csv` - 敘事弧線數據
- `*.png` - 視覺化圖表

## 延伸分析建議

### 進階質性分析
- 使用 NVivo 或 MAXQDA 進行深度編碼
- 現象學分析 (IPA)
- 扎根理論建構

### 進階量化分析
- 使用 BERT 或 GPT 進行情感分析
- 主題建模 (LDA, BERTopic)
- 時間序列預測模型

### 臨床應用
- 對照組比較分析
- 介入效能統計檢定
- 預測模型建立
