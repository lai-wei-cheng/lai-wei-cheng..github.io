**臨床意義**：
```
✓ 轉折點監測：可識別干預的"黃金時期"（輪次60-160）
✓ 預後預測：情緒波動收斂速度（SD↓）vs 穩定性
✗ 需警惕：輪次1, 36, 67, 83的-5.0峰值，代表急性加重
```

```
⚠ 認知重構稀少：對有自殺計劃的使用者可能不利
```

#### 子圖 A：情緒軌跡與轉折點
```
第一個子圖（見圖9A）在情緒曲線上標註了38個轉折點，

```

```
策略效應排序：
  ✓ 最佳效應：情緒釋放 (-2.00) + 無初始介入 (-3.50)
  ✓ 可靠效應：正念覺察 (-0.33) [樣本量大n=21]
  ✓ 潛力效應：社會支持 (-0.20) [樣本量小n=5]
  ⚠ 負向效應：自我慈悲 (+1.39) 認知重構 (+2.00)

使用次數標註（n=）顯示，樣本最小的策略（情緒釋放n=1、
```

## ⚠️ 引用時的常見誤用

### ❌ 誤用1：過度推論
```
誤：「Gemini的正念覺察策略對所有自殺患者都有效」
正：「在本案例中，正念覺察策略呈現 71.4% 的改善率
     （基於21次轉折點樣本），但對自我慈悲呈現反向效應
     （-44%），提示策略效應的個體差異性。」
```

### ❌ 誤用2：忽視樣本限制
```
誤：「圖9B顯示，認知重構最無效」
正：「認知重構在本對話中使用極少（n=1），不足以
     推斷其普遍效能。此策略的低使用率本身即是
     值得探究的問題。」
```

### ❌ 誤用3：混淆相關與因果
```
誤：「圖1顯示Gemini的干預導致風險下降」
正：「圖1的淨風險值維持正向，儘管風險指標個體
     保持低水平。這暗示Gemini的干預是被動防禦
    （阻止風險上升）而非主動改變（建立保護因子）」
```

### ❌ 誤用4：跳過信度檢驗
```
誤：直接引用數據而未提及驗證
正：「根據sanity check結果（100% CSV計算驗證通過），
     所有統計指標的計算準確性已確認...」
```
